## Three questions, one run

<CardGrid>
  <Card title="What did it do?">
    The attempts that executed the run, the agent configuration behind each, and the spans
    they left. In the run document: `attempts` and `trace`.
  </Card>
  <Card title="How did the products run?">
    The logs and errors that share the run's id or its trace. In the run document:
    `log_count` and `errors`.
  </Card>
  <Card title="Was it any good?">
    Gate decisions read from superpipeline, and the verdicts recorded in superwitness. In the
    run document: `verdicts`.
  </Card>
</CardGrid>

superwitness is a single Go binary and a Postgres database, self-hosted and MIT licensed. Start
with [what it is](/what-it-is/), then [install it](/install/).
